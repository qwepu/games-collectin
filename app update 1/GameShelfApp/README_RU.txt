GAMESHELF — обновлённый пакет для твоей базы MyDataBase

ПЕРЕД ЗАПУСКОМ
1. Открой GameShelfApp.csproj в Visual Studio.
2. Открой Db.cs и замени CHANGE_ME на пароль PostgreSQL. Сейчас база выставлена в MyDataBase.
3. Убедись, что контейнер PostgreSQL запущен в Docker Desktop и опубликован порт 5432.
4. В Visual Studio: Сборка -> Восстановить пакеты NuGet, затем Сборка -> Собрать решение.
5. Нажми зелёную кнопку запуска.

БАЗА ДАННЫХ
- В pgAdmin выбери сервер dirka -> Databases -> MyDataBase -> Tools -> Query Tool.
- requirements_setup.sql — схема и справочники. Он использует CREATE TABLE IF NOT EXISTS, но не исправляет уже существующие таблицы с другой структурой. Если таблицы есть, сравни колонки до выполнения.
- seed_100_games.sql — добавляет 100 учебных записей в games. Это демонстрационные названия, не реальный каталог.
- create_limited_db_user.sql — необязательная заготовка для отдельной роли приложения. Замени пароль перед запуском.

ПЕРВАЯ УЧЁТНАЯ ЗАПИСЬ АДМИНИСТРАТОРА
Регистрация в приложении создаёт пользователя с ролью user. После регистрации в Query Tool выполни, заменив login:
UPDATE users SET role_id=(SELECT id FROM roles WHERE name='admin') WHERE login='ТВОЙ_ЛОГИН';
Затем войди заново.

BACKUP
В pgAdmin: правой кнопкой по MyDataBase -> Backup... -> Format Custom -> укажи путь к файлу с расширением .backup -> Backup.
Восстановление: создай новую пустую базу -> правой кнопкой по ней -> Restore... -> выбери .backup.

GIT
В терминале в папке проекта:
git init
git add .
git commit -m "Initial GameShelf"
Не сохраняй реальные пароли, резервные копии и личные данные в публичном репозитории.

ВАЖНО ПРО СООТВЕТСТВИЕ ТЕХНИЧЕСКОМУ ЗАДАНИЮ
Этот архив — рабочая базовая версия: вход/регистрация с BCrypt, каталог, поиск и фильтры, личная коллекция. SQL-файлы помогают подготовить схему, тестовые данные, отдельную роль БД и резервное копирование.
Текущая форма приложения ещё НЕ реализует весь список из задания: полный CRUD для всех сущностей с удалением/изменением, управление ролями в UI, сортировку по нескольким полям, полноценное рассмотрение предложений, экспорт Excel/PDF и встроенный мастер резервного копирования. Не сдавай её как полностью готовую без доработки и тестирования этих пунктов.

ПАРАМЕТРЫ БАЗЫ
Host=localhost;Port=5432;Database=MyDataBase;Username=postgres;Password=...
Если Docker публикует другой порт, поменяй Port. Имя сервера в pgAdmin (dirka) не равно имени базы; на скриншоте база — MyDataBase.
